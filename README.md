# 🛍️ Nike E-Commerce Store

A fully responsive Nike-themed e-commerce web application built using **ReactJS**, **Tailwind CSS**, **Redux**, and **Vite**. This project showcases product browsing, filtering, cart management, and smooth UI/UX transitions — all powered with modern frontend development practices.

---

## 🚀 Features

- 🖥️ **Fast & Scalable** app bootstrapped with Vite
- 🎨 **Tailwind CSS** for utility-first and responsive styling
- 🛒 **Cart management** using **Redux Toolkit**
- 🔍 **Product listing and details** fetched from a dummy API
- 💡 Clean and minimal **Nike-themed UI**
- 📱 **Mobile-friendly design** for all screen sizes

---

## 🛠️ Tech Stack

- **ReactJS**
- **Vite**
- **Tailwind CSS**
- **Redux Toolkit**
- **Axios / Fetch API**

## 📁 Installation & Running Locally

```bash
# 1. Clone the repository
git clone https://github.com/your-username/nike-ecommerce.git

# 2. Navigate to the project folder
cd nike-ecommerce

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
